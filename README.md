# 📊 تحليل قائمة فوربس للمليارديرات لعام 2022
### (Forbes Billionaires 2022 Data Analysis)
هذا المشروع عبارة عن مفكرة تفاعلية (**Jupyter Notebook**) تهدف إلى استكشاف وتحليل بيانات أغنى أغنياء العالم بناءً على قائمة فوربس لعام 2022. يتم التركيز في المشروع على استخراج الإحصائيات الحيوية، وتوزيع الثروات، وتحليل البيانات ديموغرافياً.
## 📋 محتويات المشروع
يتضمن الملف العمليات التالية:
 * استيراد وفحص البيانات: قراءة ملف Forbes-2022-Billionaires-db.csv والتحقق من جودة البيانات والأعمدة.
 * الإحصاء الوصفي: معرفة عدد المليارديرات الإجمالي وتوزيع الثروات.
 * تحليل الأثرياء: استخراج بيانات الشخص الأغنى في العالم وتفاصيل ثروته وجنسيته.
 * التصور البياني: استخدام مكتبات Seaborn و Matplotlib لتمثيل البيانات بشكل مرئي (Visualizing Data).
## 🛠️ الأدوات والمكتبات المستخدمة
تم بناء هذا التحليل باستخدام لغة Python والمكتبات التالية:
 * Pandas: لمعالجة وتحليل البيانات وتصفيتها.
 * Matplotlib: لإنشاء الرسوم البيانية الأساسية.
 * Seaborn: لتحسين المظهر الجمالي للرسومات البيانية والإحصائية.
## 🗂️ هيكل البيانات
يحتوي ملف البيانات على 2668 سجلاً و 22 عموداً، تشمل:
 * الاسم (personName).
 * صافي الثروة (finalWorth).
 * العمر (age).
 * المصدر (source) والقطاع (category).
 * الدولة والمدينة (country, city).
 * معلومات إضافية مثل السيرة الذاتية (bio) والعمل الخيري (philanthropyScore).
